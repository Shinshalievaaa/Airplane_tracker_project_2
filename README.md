# Трекер самолётов
Это программа, которая собирает данные о самолетах в воздушных пространствах тех стран, которые выбрал пользователь

## Содержание
Для запуска - python main.py
Затем необходимо ввести название страны, над воздушным пространством которой желаете узнать данные о самолетах.
Далее названия стран через запятую для фильтрации по стране регистрации
И затем количество самолетов для вывода в топ N и диапазон высот полета через тире
После чего на экран выведется информация по заданным критериям.
